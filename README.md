# Hajjam Barbers (concept)

A concept website for a barbershop in DHA Phase 6, Lahore.
Designed and built by NexaFlow with Next.js.

- A barber pole that turns in the hero
- Price board with time for every service
- Booking with barber, day and time slot, sent to WhatsApp
- Dulha (groom) package for weddings

```bash
npm install
npm run dev
```

All text, prices, hours and photos are in `components/data.ts`.
